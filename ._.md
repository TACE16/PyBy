#    {#-}

    ( ) __  .     `2 + 3`.      .

__      ,   `+`      .     ,    __   .  , `2`  `3`   . 

## 

     .

  ,        . , `2 + 3`  ,     :

```python
>>> 2 + 3
5
>>> 3 * 5
15
>>>
```

      :

- `+` ()
    -   
    - `3 + 5`  `8`. `'' + ''`  `''`.

- `-` ()
    -       ;    ,   .
    - `-5.2`    . `50 - 24`  `26`.

- `*` ()
    -          .
    - `2 * 3`  `6`. `'' * 2`  `''`.

- `**` ()
    - -   
    - `3 ** 4`  `81` ( `3 * 3 * 3 * 3`)

- `/` ()
    - - - 
    - `13 / 3`  `4.333333333333333`

- `//` ( )
    - - - ,       __ .     ,         . 
    - `13 // 3`  `4`
    - `-13 // 3`  `-5`
    - `9//1.81`  `4.0`

- `%` ()
    -   
    - `13 % 3`  `1`. `-25.5 % 2.25`  `1.5`.

- `<<` ( )
    -  ,     . (       0  1  )
    - `2 << 2`  `8`. `2`  `10`  .
    - 2   , 8    `1000`  .

- `>>` ( )
    -  ,     .
    - `11 >> 1`  `5`.
    - `11`   `1011` ,       `101`  ,   `5` .

- `&` (  )
    -     :   `1`   ,  `1`  . ,  `0`  .
    - `5 & 3`  `1` (`0101 & 0011`  `0001`)
    
- `|` (  )
    -   :   `0`  ,  `0`  . ,   `1` . 
    - `5 | 3`  `7` (`0101 | 0011`  `0111`)
    
- `^` (  ) 
    -   :   ( `1  0`)   ,  `0`. ,  `1`.
    - `5 ^ 3`  `6` (`O101 ^ 0011`  `0110`)

- `~` (  )
    -       -(+1) 
    - `~5`  `-6`.   http://stackoverflow.com/a/11810203   

- `<` ()
    - , -     .    `True`  `False`  .      .
    - `5 < 3`  `False`  `3 < 5`  `True`.
    -   : `3 < 5 < 7`  `True`.

- `>` ( )
    - , -     .
    - `5 > 3`  `True`.    ,      . ,    `False`.

- `<=` (  )
    -   -       .
    - ` = 3;  = 6;  <= `  `True`

- `>=` (   )
    -   -      .
    - ` = 4;  = 3;  >= 3`  `True`

- `==` ()
    -     
    - ` = 2;  = 2;  == `  `True`
    - ` = 'str';  = 'stR';  == `  `False`
    - ` = 'str';  = 'str';  == `  `True`

- `!=` ()
    -    
    - ` = 2;  = 3;  != `  `True`

- `not` ( )
    -   `True` ,  `False`- .   `False` ,  `True`- .
    - ` = True; not `  `False`.

- `and` ( )
    - ` and `  `False`,    `False`  `False`,     
